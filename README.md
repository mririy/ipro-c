# Ай Про · IPROSCHOOL — сайт школы, версия C

Версия C полного сайта частной школы полного дня «Ай Про» (Ялта) — в духе rocketbank.ru, в цветах школы. Разделы, их порядок и тексты — как в версии A (`ipro-a`), меняется оформление:

- у каждой главы свой цвет из одной семьи: глубокий синий школы, небо, солнце и голубой, а к ним приглушённые «детские» оттенки — персик, мята, абрикос; на светлых главах мягкие пятна солнца и неба, границы глав — плавной дугой;
- заголовки строчными буквами широким шрифтом Unbounded, слова-акценты — переливом: на чёрном от солнца к небу, на светлом — синим школы; цвета школы — в акцентах, а не сплошной заливкой;
- подписи, кнопки и метки — моноширинным JetBrains Mono капсом, текст — Onest;
- стеклянные полупрозрачные карточки;
- кнопка «Записаться на пробные дни» всегда внизу экрана, помощник «Вопросы?» — значком в шапке;
- первый экран из двух частей: сначала, как в версии A, видео в круге-солнце с надписью по кругу — при прокрутке круг раскрывается во весь экран, а солнце уменьшается и улетает в логотип; затем видео сжимается в стеклянную карточку и уходит вниз, а на чёрном появляются три шага к зачислению;
- шапка — скруглённая плашка с отступом от краёв; цвет полосы браузера не задан, поэтому внизу на iPhone видна страница, а не синяя полоса;
- 3D-макет особняка лежит прямо на переливе, ночная сцена и все окна — как в версии A.

## Устройство

Сайт собран из версии A: те же `gen/content.py` и общий сценарий `assets/js/site.js` со стилями `assets/css/site.css`. Поверх них — `assets/css/site-c.css` (оформление версии C) и `assets/js/site-c.js` (первый экран). Небо глав — `C_SKY` в `gen/build.py`.

Сайт статический: **Settings → Pages → Deploy from a branch → `main` / root**. Пересборка после правки текстов: `pip install pillow && python3 gen/build.py .`

Шрифты Unbounded, JetBrains Mono и Onest — Google Fonts (OFL), иконки — [Lucide](https://lucide.dev) (ISC).
